# ADR-001：小星定位与 AI 会议能力

## 背景

小星与大智同级孵化。早期曾做成「仅本机麦问答」的薄语音桌面；产品要求小星**同样具备 AI 会议能力**，同时保持农业领域口径独立。

## 决策

1. **产品**：农业 AI 助理 = 农服知识库 + **AI 会议**（听写 / 唤醒 / 口播 / 半双工等）。  
2. **工程**：与 `desktop/` 代码解耦；会议模式从 `dev_knowledge/shared/` 学习后在 `xiaoxing/` 独立实现。  
3. **知识**：业务 FAQ/Wiki 仅在 `xiaoxing/knowledge/`；不共用大智园所口径。  
4. **里程碑**：先对齐会议主路径（听写→唤醒→口径口播→会话沉淀），再按需引入副驾驶 / Focus / Wiki2。

## 后果

- 文档与 Cursor rules 不得再写「小星不做会议」。  
- 禁止为图省事 `require('../desktop/...')`。  
- 会议相关踩坑升格 `shared/`，农服专属留本目录。
