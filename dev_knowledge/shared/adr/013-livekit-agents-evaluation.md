# ADR-013 · LiveKit Agents 独立评估（不与 Bot 捆绑）

状态：**暂缓迁移**（2026-11-26）

## 背景

会议控制 MVP 已选定火山 RTC VoiceChat 作为「房内 AI 成员」路径；LiveKit Agents 在轮次/自适应打断上有成熟模式，曾被列为备选。

## 决策

1. **现阶段不迁移**媒体面到 LiveKit。  
2. LiveKit 评估与 **Vexa Bot 接入解耦**：Bot 解决「外部会议转写」；RTC 解决「同房间双向语音」。  
3. 仅当出现以下触发条件之一时，另开评估立项：  
   - 火山 VoiceChat 成本/配额无法满足灰度目标；  
   - 打断/多人或房间控制能力长期不满足产品；  
   - 需要自建 WebRTC 且团队具备运维带宽。  

## 评估清单（触发后执行）

| 项 | 内容 |
|----|------|
| 功能 | Agent 生命周期、自适应打断、与现有 Ask/摘要衔接成本 |
| 成本 | 媒体分钟、STT/TTS、自建 vs Cloud |
| 迁移面 | Token、房间、桌面订阅、回调验签 |
| 风险 | 双运行时、中国区合规与延迟 |

## 后果

- 开源参考继续用于测试设计（见 `meeting-control-mvp.md`），不引入生产依赖。  
- 当前生产路径：火山 RTC +（可选）Vexa 转写 Bot + MeetingEvent 契约。
