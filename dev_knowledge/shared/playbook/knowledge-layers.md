# Playbook：业务知识分层（各产品私有）

```text
Raw（只追加）→ Wiki 词条（口播/事实/边界）→ FAQ L1 → 会中 Query
                                    ↑
                         inbox / sessions 会后升格
```

- 运行态目录：`<product>/knowledge/`（及可选 `knowledge_wiki/`）。  
- 研发方法：本 playbook + 产品业务文档（如根目录 `大智知识库架构.md`）。  
- **不要**把业务话术写入 `dev_knowledge/`。
