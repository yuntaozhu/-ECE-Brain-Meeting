# 小星 · 产品形态（语音 + AI 会议）

小星是与大智同级的独立助理：**农业领域知识** + **AI 会议能力**（听写 / 唤醒 / 口播 / 半双工等）。

## 一句话

小星听得见会场、答得稳农服口径、补得上知识库：会议听写与唤醒「小星」→ FAQ/Wiki → TTS；没答上的进看板复盘入库。

## 与大智边界

| | 大智 `desktop/` | 小星 `xiaoxing/` |
|--|--|--|
| 领域 | 教育 / 园所等 | 农业（草莓等） |
| AI 会议 | 参考实现 | **要对齐落地**（代码独立） |
| 业务知识 | `desktop/knowledge/` | `xiaoxing/knowledge/` |
| 跟进 | 会务 / Kaiban | 农服补库看板 |

会议能力清单与落地铁律见 `dev_knowledge/shared/playbook/meeting-assistant.md`。
