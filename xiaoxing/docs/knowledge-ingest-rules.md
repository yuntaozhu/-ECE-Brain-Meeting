# 小星知识入库规则（抓什么 / 不抓什么）

来源：会后知识闭环 + 东方城乡报 / 市农委农业技术 / 正版书目盘点（2026-11-23）。

## 1. 三轨入库

| 轨道 | 材料类型 | 怎么进库 |
|------|----------|----------|
| **A 公开爬取** | 官网栏目、数字报公开稿、农技意见网页版 | `crawl-sources.json` 白名单 → Firecrawl → `raw/` → 审定升格 Wiki/FAQ |
| **B 授权摘录** | 正式出版物、标准 PDF、丛书章节 | 正版采购/授权 → 人工摘录 → `raw/manual` → Wiki/FAQ |
| **C 书目索引** | 仅书名、编者、用途、匹配板块 | `raw/manual/*-catalog.md`；**无正文** |

## 2. 可爬（白名单）

- 上海市农委 **农业技术**栏目：https://nyncw.sh.gov.cn/nyjs/index.html  
  - 检索：`上海市水稻栽培技术意见`（历年网页版可另存 PDF 归档至 `raw/manual/sh-rice-opinions/`）  
  - 配套：`一种就管`、`机插稻育秧栽培技术要点`
- 东方城乡报数字报：https://www.dfcxb.com  
  - 关联：「上农 APP」「上海三农」（公众号以官方为准；App 登录墙后不爬）
- 既有学会/农科院/行情源与水稻公开首页：见 `schema/crawl-sources.json`

## 3. 定向关键词（草莓 / 柑橘 / 水稻）

详见 `schema/ingest-keywords.json`：

| 栏目簇 | 关键词 | 入库层 |
|--------|--------|--------|
| 要闻/政策 | 沪郊动态、区域发展、涉农政策、三农参考 | 政策层 |
| 产业与农技 | 新主体、新农人、龙头、合作社、农技指导、品种与种植养殖 | 技术层 |
| 乡村文化与生活 | 阡陌、绿野、科普、生活 | 文化旁路（不作规程） |
| 三农实用 | 生产实践、技术与经营案例 | 技术层（标注产地） |

## 4. 禁止

- 电商图书全文、盗版 PDF、未授权扫描  
- 《草莓研究进展》《世界草莓大会译丛》《中国水稻品种志》等 **整书爬取**  
- 「上农 APP」登录墙内容、完整手机号  
- B2B 盲爬；文化软文当剂量/补贴标准

## 5. 升格路径

```text
raw（只追加）→ 审定 → wiki/concepts + faq-*.txt → wiki2:index
缺口 → inbox / ingest-task → 指定 source_ids 再爬或手工摘录
```
