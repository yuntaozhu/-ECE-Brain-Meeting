# raw/manual · 授权摘录与书目

## 放什么

| 类型 | 示例 | 要求 |
|------|------|------|
| 授权摘录 | 丛书章节摘要、标准可执行摘要 | 已获授权或合理使用；注明出处与页码 |
| 公开意见归档 | 市农委水稻技术意见另存 PDF | 文件名带年份；来源 URL 写入说明 |
| 书目索引 | `book-catalog-*.md` | **仅元数据**，无正文 |

## 目录建议

- `sh-rice-opinions/` — 历年《栽培技术意见》《一种就管》《机插育秧要点》归档  
- `book-catalog-rice-fruit.md` — 水稻/果树正版书目  

## 不放

未授权全书 PDF、网店下载包、盗版扫描、App 登录墙内容、用户隐私。

## 升格

摘录审定 → `wiki/concepts` + `faq-*.txt` → `npm run wiki2:index`。  
规则：`docs/knowledge-ingest-rules.md`。
