# 柑橘公开资料入口

## 口播
柑橘通识可先查中国农科院柑桔研究所等公开站；上海看市农委「农业技术」栏目、东方城乡报与上海农科院林果相关公开动态。这些是索引入口，栽培操作以正式文本和当地农技为准。

## 事实
- 中国农业科学院柑桔研究所（公开站检索「中国农科院柑桔研究所」）— 育种、栽培、植保与产业资讯入口
- 上海市农业农村委员会·农业技术：https://nyncw.sh.gov.cn 栏目内果树/柑橘相关技术意见（按当季检索）
- 东方城乡报 / 上海三农：https://www.dfcxb.com — 地产柑橘/橘类报道与科普旁路
- 上海市农科院：https://www.saas.sh.cn — 林果所公开成果与动态
- 白名单：`crawl-sources.json` 中 `sh-nyncw-nyjs`、`dfcxb`、`saas` 等；关键词见 `ingest-keywords.json`
- 正版丛书柑橘分册：仅书目发现 → 授权摘录 → Wiki；见 [[book-ingest-policy]]

## 边界
不把机构新闻标题当处方；网店图书页禁止当全文源。
