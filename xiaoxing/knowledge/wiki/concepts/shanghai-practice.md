# 上海草莓产区实践入口

## 口播
上海草莓可关注市农科院林果所与各区农技渠道：金山有繁育地方标准与产业联合体实践，青浦白鹤是知名产区，嘉定、松江、浦东农委旬报更新较勤。本地操作优先本地源。

## 事实
- 上海市农业科学院：林果所（栽培/育种）；农业农村部植物新品种测试（上海）分中心（草莓 DUS / 真实性）
- 金山区农技中心 + 鑫品美草莓产业联合体：地方标准 DB 31116/Z 008-2025
- 青浦白鹤：白鹤草莓研究所（镇政府体系），文化节期间技术资料较集中
- 嘉定 / 松江 / 浦东：公众号季节性管理意见
- 嘉定公开推介（2025–2026）：区农技中心等组织地产优质草莓宣传；常见展示品种含红颜、越秀、娇美一号、紫金香雪、申莓系列等（以当季活动稿为准，有效至见 raw/xunbao）
- 技术培训常邀请市农技中心、交大、市农科院专家讲绿色生产与新优品种（报道口径，非操作规程全文）

## 边界
不把某一产区经验直接写成全市强制标准；补贴与立项走政务渠道；推介活动名单不做产量承诺。
