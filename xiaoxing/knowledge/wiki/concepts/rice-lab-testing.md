# 水稻检测指标通识入口（轻量）

## 口播
公开科普常按苗、叶、秸秆、汁液、稻谷几类样本谈检测方向，比如抗逆酶系、光合色素、纤维组分、品质与安全指标。库内只作课题选型通识；具体方法、限量与送检标准以国标、行标和正规检测机构为准，我不开检测处方。

## 事实
- 样本维度线索：幼苗 / 叶片 / 秸秆 / 汁液 / 稻谷（汇编「检测指标体系」）
- 方向举例：抗逆与抗氧化酶、光合与胁迫、生物质纤维、代谢与养分、淀粉蛋白与安全残留
- 数据性质：机构科普转述（含未标年条目），不作法定限量背书
- 与 [[rice-yield-measure]] 测产、[[rice-taste-score]] 食味评价互补

## 边界
不编造国标编号与限量值；不做「打多少药刚好过检」类规避指导；安全残留问题指向正式标准与有资质实验室。
