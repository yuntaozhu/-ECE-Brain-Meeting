# 上海柑橘实践入口（骨架）

- 丛书定位：上海果树全产业链·柑橘分册 = 第二作物摘录候选（P1），草莓分册优先
- 缺口任务：会后 `gap_kind=crop_bootstrap`、product=柑橘 → 建议源 nyjs / dfcxb / saas

## 边界
