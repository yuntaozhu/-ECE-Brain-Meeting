# Leading Conversational Search by Suggesting Useful Questions（Rosset 等，WWW 2020）

## 一句话
下一问要有用：把话题向前带一步，而不只是相关。

## 要点
- 提出 usefulness，区别于经典 relevance。
- 用搜索会话里的下一跳做弱监督，训练排序与生成。

## 对本仓库
- **采用**有用性：加深、具体化、下一步。
- **不采用**训练 GPT-2；弱信号用详版小节顺序与会议日志。
