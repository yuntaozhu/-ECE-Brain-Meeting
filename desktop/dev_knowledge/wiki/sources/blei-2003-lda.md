# Latent Dirichlet Allocation（Blei、Ng、Jordan，2003）

## 一句话
LDA 把集合里的每一项看成若干主题的有限混合；一项需要够长，主题分布才代表得了这篇文档。

## 要点
- 三层贝叶斯模型：文档是主题的混合，主题是词的分布。
- 摘要写明：主题概率给文档一个显式表示。
- 比较对象是 unigram 混合和概率 LSI，任务是文档建模、分类、协同过滤。
- 一句转写不是这种「文档」。

## 对本仓库
- **不采用**把单轮口播当 LDA 文档做在线主题推断。
- 卡片选择仍是离散假设的后验，不是文档—主题混合。
