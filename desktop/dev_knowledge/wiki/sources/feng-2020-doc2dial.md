# doc2dial: A Goal-Oriented Document-Grounded Dialogue Dataset（Feng 等，EMNLP 2020）

## 一句话
先按文档里的条件与做法排对话流，再收集话轮。

## 要点
- 文档标 precondition / solution，再组成对话流。
- Anthology 2020.emnlp-main.652。

## 对本仓库
- **采用**：落地、收费、收益保障等卡按「条件 → 做法」排链。
- 不引入 crowdsourcing 平台。
