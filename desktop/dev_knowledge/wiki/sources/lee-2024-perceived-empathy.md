# Large Language Models Produce Responses Perceived to be Empathic（Lee 等，2024）

## 一句话
人评 LLM 回复比人写更「共情」；测的是感知，不是事实接地。

## 要点
- 各模型文风可辨。
- 共情分数高不等于答案有证据。
- 适合学「先承认关切、短句」的口吻，不适合当开口阈值。

## 对本仓库
- **部分采用**：compose 口吻可参考。
- **禁止**：用共情分数替代后验 / 对齐门槛；禁止编造检索里没有的安慰承诺。
