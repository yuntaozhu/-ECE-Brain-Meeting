# QuAC: Question Answering in Context（Choi 等，2018）

## 一句话
学生连着问，老师只能用文中短段作答，答不出就标不能答。

- 约 14K 对话、100K 问句；答案是 Wikipedia 段落中的 span。
- arXiv:1808.07036 · ACL D18-1241。

## 对本仓库
- **采用**：连问协议；撑不住标 gap。
- **不采用**抽 span 模型。
