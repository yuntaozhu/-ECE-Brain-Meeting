# 打断 / 唤醒 · 语音验收用例（v2）

会场复测前：`npm run desktop` 重启（改过 main / schema / HostAsr）。  
自动化冒烟：`node desktop/scripts/smoke-barge-stop.cjs`。

判据日志关键字：`barge-in-stop` / `barge-in-asr` / `唤醒短路打断` / `跳过回灌唤醒` / `静音断句`。  
失败时记：是否仍在播、ASR 原文、是否出现 `45000292`。

## A. 必须过（P0）

| # | 步骤 | 口令时机 | 期望 |
|---|------|----------|------|
| A1 | 开场问候播到「我是大智…」 | **不说话** | 不出现 `wake-asr`；可有回灌转写，不当唤醒 |
| A2 | 同 A1 | 播完后说「大智」 | `wake-asr` 或正常叫名巡检；TTS 停（若仍在 hold） |
| A3 | 问「全园美语是什么」，答到**一半** | 清晰说「谢谢大智」 | ≤1.5s 内停播；日志 `barge-in-stop`；不连环念「退回聆听」 |
| A4 | 同上，答到一半 | 「大智听我说」 | 立刻停；`barge-in-asr` / INTERRUPT |
| A5 | 同上，答到一半 | 「大智」 | 停播 + 唤醒巡检（`wake-asr`） |
| A6 | 长答接近结尾 | 「谢谢大智」（可略晚） | 仍能停；粘连句「…引擎。谢谢大智」也认 |
| A7 | 打断成功后静默 5s | — | **无**新的 HostAsr 建连风暴；无连续 `45000292` |
| A8 | 长答播放中（勿说话） | — | 即使 ASR 出现「整合 a 区大智」类回灌，**不** `wake-asr`；可有「跳过非干净唤醒」 |
| A9 | 中途「谢谢大智」成功后 | — | 进静默；**不**再念「退回聆听」；界面无该句「合成中」 |

## B. 变体（P1）

| # | 口令 | 期望 |
|---|------|------|
| B1 | 「谢谢大」「嗯谢谢大智」「谢谢大致」 | 升格 STOP，停播 |
| B2 | 「停止大智」「大智休息」 | 停播 |
| B3 | 「谢谢大家」（答中夹一句） | **不停**（勿误打断） |
| B4 | 线缆回灌明显时只听播报 | 不误唤醒；允许偶发静音断句日志 |
| B5 | 播中说「谢谢大智」时若正巧静音窗 | 口令出现后应清窗并打断（勿整段吞掉） |

## C. 负例

| # | 场景 | 期望 |
|---|------|------|
| C1 | ASR 只有「我是大智。」（问候回灌） | `跳过回灌唤醒`，不进问答 |
| C2 | ASR「大智」且当前口播含「呼叫大智」 | 仍可唤醒（短叫名不当纯回灌） |
| C3 | 未播报、IDLE 说「谢谢大智」 | 进静默/STOP 模式，不报错 |

## 操作建议

1. 喇叭勿贴麦；音量中等；先做 A1→A3→A7。
2. A3 失败：看日志是口令未上屏、还是已 `barge-in-stop` 但声未停（TTS 路径）。
3. A1 失败：确认 `looksLikeSpeakEcho` 对带句号「我是大智。」为真。
