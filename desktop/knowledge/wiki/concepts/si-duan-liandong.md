# 四端联动

## 口播
四端联动是孩子学、老师教、回家续、成果显：幼儿端、教师端、家庭端和成果展示打通，链路通了美语才能成招生招牌。

## 事实
四端指幼儿学习（ABCmouse / ABC说 / 菲教等）、教师备课与课堂用语（Teacher说）、家庭延续（Family说）、成果可见（AI测评与成果展）。缺一端就会断链。

## 边界
不要把四端说成四个独立产品各自卖；也不要用「大智」自称去解释四端定义。
