# 申请节奏：先摸清再申请

## 口播
别急着直接申请。先摸清全园教师日常用英语的意愿和现有美语账号使用情况，再走申请流程，避免好项目做成闲置成本。

## 事实
申请前应完成执行基础盘点：教师意愿、账号使用、硬件与网络、美语主任人选。落地按行事历分阶段推进。

## 边界
不要催促「今天必须签约」。也不要说「申请了就保证招生翻倍」。
