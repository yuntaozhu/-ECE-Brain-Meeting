# 八大核心权益一览

## 口播
八大权益含 ABCmouse、ABC说、AI测评、线上菲教、Teacher说、Family说、美语成果展，以及约 1.3 倍账号使用空间。

## 事实
全园美语系统八大核心权益：1. 全园幼儿 ABCmouse 账号；2. ABC说开口工具；3. AI测评；4. 每班每日线上菲教；5. Teacher说教师培训；6. Family说家长端；7. 美语成果展；8. 账号额度可扩到在籍约 1.3 倍。不要漏项，也不要额外编造第九条。

## 边界
不要把八大权益说成「只买账号」。未写明的分项单价不要口头报。1.3 倍是账号空间口径，不是招生承诺。
